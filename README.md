# Animal Shelter Management System

## Description 
This Java project uses queues to manage animals in a shelter. Dogs and cats
are added and adopted based on the order they arrived.

## Features 
- Adds dogs and cats to the shelter
- Adopt the oldest animal
- Adopt the oldest dog or cat
- Handle empty queues 
- Follow FIFO 

## How to Run
1. Open the project in IntelliJ IDEA.
2. Open Main.java.
3. Run the program to test the shelter operations.

## Testing
This program was tested using:
- Empty shelter
- Shelter with only cats
- Shelter with only dogs
- Adopting animals in FIFO order

## Technologies Used 
- Java
- IntelliJ IDEA
- Queues and LinkedLists
